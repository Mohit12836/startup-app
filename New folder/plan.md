# Setubandh: Technical Plan (v0.1)

## 1. आर्किटेक्चर

```
[Next.js वेबसाइट]   [Flutter मोबाइल ऐप]   [Admin पैनल (Next.js)]
         \                  |                    /
              ---- REST API (NestJS) ----
                |        |         |        |
           PostgreSQL  Redis   S3/R2     OTP/Push
                                (फ़ाइलें)  (MSG91, FCM)
```

एक ही API तीनों क्लाइंट को सर्व करे, ताकि नियम एक जगह रहें।

## 2. टेक स्टैक

| हिस्सा | चुनाव | कारण |
|---|---|---|
| वेबसाइट | Next.js (React, TypeScript) | SEO, तेज़ पेज |
| मोबाइल | Flutter | एक कोडबेस, Android + iOS |
| बैकएंड | NestJS (Node.js, TypeScript) | संरचना, टाइप-सेफ़्टी |
| डेटाबेस | PostgreSQL | रिलेशनल डेटा, full-text search |
| कैश / रेट-लिमिट | Redis | OTP और throttling |
| फ़ाइल स्टोरेज | Cloudflare R2 या AWS S3 | सस्ता, CDN के साथ |
| OTP (SMS) | MSG91 (या समकक्ष) | भारत में DLT-अनुपालन |
| ईमेल | AWS SES / Resend | ट्रांज़ैक्शनल मेल |
| पुश | Firebase Cloud Messaging | Android + iOS |
| सर्च | शुरू में Postgres FTS, बाद में Meilisearch | सरल शुरुआत |
| CI/CD | GitHub Actions | ऑटो टेस्ट और डिप्लॉय |
| हॉस्टिंग | AWS / DigitalOcean (मुंबई रीजन) | भारत में कम लेटेंसी |
| मॉनिटरिंग | Sentry + uptime चेक | त्रुटियाँ जल्दी पकड़ना |

*यह सिफ़ारिश है, बाध्यता नहीं। टीम को जो स्टैक आता हो, उसी पर विचार करें (जैसे Django या React Native)।*

## 3. रिपॉज़िटरी संरचना (monorepo सुझाव)

```
setubandh/
  apps/
    api/        # NestJS
    web/        # Next.js (पब्लिक + एडमिन)
    mobile/     # Flutter
  packages/
    shared/     # साझा टाइप/validation स्कीमा
  docs/         # ये .md फ़ाइलें
```

## 4. मुख्य डिज़ाइन फ़ैसले

1. **लॉगिन:** OTP-आधारित, JWT (छोटा access token + refresh token)
2. **रोल:** `founder`, `investor`, `mentor`, `visitor`, `admin` (एक यूज़र के कई रोल संभव)
3. **स्टार्टअप स्थिति:** `draft` → `pending` → `approved` / `rejected` / `suspended`
4. **वेरिफ़िकेशन:** अलग टेबल, जो प्रोफ़ाइल अप्रूवल से स्वतंत्र है
5. **फ़ाइलें:** सीधे क्लाइंट से signed URL द्वारा अपलोड, सर्वर पर टाइप/आकार जाँच
6. **भाषा:** i18n शुरू से (हिंदी/अंग्रेज़ी), स्ट्रिंग्स कोड में हार्डकोड नहीं
7. **सॉफ़्ट-डिलीट:** कोई भी डेटा तुरंत स्थायी रूप से न मिटे (DPDP डिलीट-अनुरोध की अलग प्रक्रिया)
8. **लोकेशन:** शहर/राज्य की मानक सूची (free-text नहीं), ताकि फ़िल्टर साफ़ चले

## 5. फ़ेज़ और टाइमलाइन (अनुमानित, लगभग 5-6 महीने)

| फ़ेज़ | अवधि | नतीजा |
|---|---|---|
| 0. Discovery | 2 हफ़्ते | नाम पक्का, 10-15 फ़ाउंडर इंटरव्यू, कॉम्पिटिटर नोट |
| 1. Design | 3 हफ़्ते | वायरफ़्रेम, UI, ब्रांड शीट, डेटाबेस डिज़ाइन |
| 2. MVP Build | 8-10 हफ़्ते | API, वेब, मोबाइल, एडमिन |
| 3. Testing | 2-3 हफ़्ते | QA, सिक्योरिटी जाँच, 20-30 स्टार्टअप्स के साथ बीटा |
| 4. Launch | 1-2 हफ़्ते | Play Store/App Store, वेबसाइट लाइव, इंदौर इवेंट |
| 5. Growth | लगातार | फ़ीडबैक, Phase 2 फ़ीचर्स |

## 6. बजट (मोटा अंदाज़ा, केवल दिशा के लिए)
- MVP विकास: ₹8-20 लाख (टीम, एजेंसी बनाम इन-हाउस और स्कोप पर निर्भर)
- मासिक इंफ़्रा: शुरू में लगभग ₹5-15 हज़ार
- Play Store एक बार का शुल्क और Apple Developer का सालाना शुल्क अलग (वर्तमान दरें खुद जाँचें)
- असली कोटेशन स्कोप तय होने के बाद ही संभव

## 7. जोखिम

| जोखिम | असर | उपाय |
|---|---|---|
| सरकारी प्लेटफ़ॉर्म्स (Sayuj, Startup India) से मुक़ाबला | यूज़र न जुड़ें | स्थानीय फ़ोकस, हिंदी-पहले, ऑफ़लाइन इवेंट |
| "Setu" से मिलते-जुलते नाम/ट्रेडमार्क विवाद | री-ब्रांडिंग का ख़र्च | नाम पक्का करने से पहले ट्रेडमार्क सर्च + वकील |
| फ़र्ज़ी प्रोफ़ाइल | भरोसा गिरे | वेरिफ़िकेशन, रिपोर्ट सुविधा |
| शुरुआत में कम स्टार्टअप ("ख़ाली प्लेटफ़ॉर्म") | कोई रुचि न ले | लॉन्च से पहले 50+ स्टार्टअप्स की मैन्युअल ऑनबोर्डिंग |
| DPDP अनुपालन में चूक | कानूनी जोखिम | शुरू से सहमति, पॉलिसी, वकील की समीक्षा |
| SMS OTP की लागत/DLT मंज़ूरी में देरी | लॉन्च अटके | DLT पंजीकरण जल्दी शुरू करें, ईमेल OTP विकल्प रखें |

## 8. Phase 2 / 3 (बाद में)
- **Phase 2:** निवेशक/मेंटर प्रोफ़ाइल, इन-ऐप चैट, इवेंट्स + RSVP, पुश नोटिफ़िकेशन
- **Phase 3:** जॉब्स/इंटर्नशिप, सरकारी योजनाएँ, प्रीमियम लिस्टिंग, दूसरे शहर (भोपाल, जयपुर, पुणे)

## 9. Go-to-Market (इंदौर पहले)
1. IIM इंदौर, IIT इंदौर, STPI और स्थानीय इन्क्यूबेटर/स्टार्टअप सेल से संपर्क (पार्टनरशिप की पुष्टि अभी बाक़ी)
2. पहले 100 स्टार्टअप्स को मुफ़्त "Founding Member" बैज
3. मासिक मीटअप, LinkedIn और WhatsApp कम्युनिटी
4. सफल होने पर अगला शहर
